Privacy

Prove-It Mini plugin and this website · updated 20.10.2026

The plugin collects nothing

Prove-It Mini runs only on your computer. It makes no network requests, calls no model, and sends no telemetry. It runs the test command you configured and writes its state and gate log to .prove-it/ inside your repository. That folder stays on your machine; setup adds it to git's info/exclude, so it is not committed by default.

This website

  • No cookies, no third-party scripts, no third-party fonts.
  • Page views may be counted by GoatCounter without cookies or personal data.
  • If you join the waitlist, Buttondown stores your email. It is used once, to tell you when Pro is on sale, then deleted unless you buy or ask to stay. Every email has a one-click unsubscribe.
  • The site is hosted on GitHub Pages; GitHub may log requests as described in its own privacy statement.
